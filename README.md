# BoltFix - Smart Home Repair & Maintenance Platform

**BoltFix** is a smart service platform that connects users with verified technicians for fast, reliable home repairs and maintenance across Egypt.

## 🚀 Live Demo

Experience BoltFix in action:  
🔗 [https://iti-grad-project.vercel.app/](https://iti-grad-project.vercel.app/)

## 🌟 Vision

To bridge the gap between skilled technicians and households, ensuring every home has access to trusted repair services.

## 🎯 Mission

To provide an intuitive and seamless interface, making it easy for users to book trusted technicians for various home maintenance needs.

## 🔧 Features

- **Verified Technicians**: Only certified professionals are listed.  
- **Seamless Booking**: Schedule appointments with ease.  
- **Secure Access**: Authentication and route protection using **Auth Guards**.  
- **Firebase Integration**: Handles user authentication, database, and storage.  

## 🛠️ Technologies Used

- **Frontend**: Vue.js  
- **Authentication & Database**: Firebase (Auth, Firestore, Storage)  
- **Routing Protection**: Vue Router with Auth Guards  
- **Deployment**: Vercel
